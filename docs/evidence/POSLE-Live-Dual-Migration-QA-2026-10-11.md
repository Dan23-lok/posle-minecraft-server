# Проверка двух фонариков на копии действующего мира

11 октября 2026 г. Проверялся только локальный стенд `D:\1-Game\support\staging-live-dual-flashlight-20261011` на `127.0.0.1:25597`. Исходник — проверенный архив основного `world-v2`, конфигурации и AuthMod. Действующий `D:\1-Game` и тестовый `D:\2-Test` не изменялись.

## Результаты

| Проверка | Наблюдение |
| --- | --- |
| Сервер | Forge 1.20.1 / 47.4.10 с 22 основными JAR и дополнительным Dynamic Flashlight 2.1.0 дошёл до `Done` на локальном порту. Powered Flashlight оставлен для совместимости предметов. |
| Первое открытие копии | Forge предупредил о перенумерации `flashlight:temporary_light`, `flashlight:flashlight`, `flashlight:battery`. Это риск миграции, а не доказательство сохранности каждого блока. |
| Повторное открытие | После сохранения и штатной остановки третья загрузка дошла до `Done`; 0 предупреждений `Object did not get ID` и 0 фатальных ошибок в журнале этой загрузки. |
| Клиент | Отдельный Forge-клиент с 25 JAR, включая оба фонаря, подключился к копии мира; серверный журнал зафиксировал вход одного тестового игрока. Меню показывало 32 загруженных мода, но отдельный F2 этого экрана не сохранён. Тестовый игрок оставался без регистрации AuthMod, поэтому права, инвентарь владельца и полноценное выживание этим опытом не проверены. |
| Сохранение | После `save-all`, отключения клиента и штатного `stop` файл данных владельца в копии побайтно совпал с архивом и текущим основным файлом. Файл AuthMod также побайтно совпал с архивом. Новый тестовый игрок получил отдельный файл. Это не тест загрузки старого инвентаря в клиенте. |
| Производительность | Один F3-кадр показал 60 FPS с VSync 60 на RTX 3060, 1786/4096 МБ Java heap и отключённые шейдеры. Нет измерения 1% low, слабого ПК или нескольких игроков. |
| Завершение | Клиент отключён через меню и закрыт; сервер дважды остановлен командой `stop` с сохранением всех измерений. Порт стенда закрыт. Основной сервер продолжал слушать 25565, тестовый — 25570. |

Исходные F2-кадры клиента на копии мира: [ночная сцена](./POSLE-Live-Copy-Dual-Client-Night-F2-20261011.png), [F3 с версией, модами, FPS и состоянием шейдера](./POSLE-Live-Copy-Dual-Client-F3-20261011.png). Это кадры локальной копии процедурного мира, а не готовой Земли.

Дополнительные направленные световые тесты, включая сравнение с DMS и сохранение обоих тестовых предметов, находятся в [отчёте Dynamic Flashlight](./Dynamic-Flashlight-QA.md). Публичный клиент v9 пока несовместим с сервером, если добавить Dynamic только на сервер; поэтому основной сервер не переключён.

## Оставшиеся ворота

- Выпустить синхронное обновление клиента и сервера с проверенным установщиком и безопасным обновлением настроек.
- Проверить зарегистрированный вход владельца через его TLauncher, старый инвентарь, блоки света и оба предмета после миграции и отката.
- Повторить ночные кадры с реальным Low и DMS на конечной сборке; дальний свет с DMS пока слабый.
- Доказать производительность на слабом ПК и с несколькими игроками.
