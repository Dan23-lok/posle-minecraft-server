# Ворота приёмки «ПОСЛЕ»

Срез 11.10.2026. Идентификаторы A01–G10 соответствуют разделу 31 личного
мастер-задания владельца. **Любой не названный ниже сценарий имеет статус
UNVERIFIED.** Сценарий проходит только целиком, в требуемой среде и с
воспроизводимым доказательством. Изолированный стенд не засчитывается как
приёмка основного мира.

Отсутствие доказательства не трактуется как успех. Прежде чем назвать проект
готовым, нужно закрыть все A–G с клиентом, игроками, игровыми снимками,
сохранением после перезапуска и повторной проверкой всех изменённых областей.
