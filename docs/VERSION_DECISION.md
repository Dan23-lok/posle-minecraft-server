# Версия игры для «ПОСЛЕ» — решение на 11.10.2026

**Действующая совместимая база:** Minecraft Java 1.20.1, Forge 47.4.10,
Java 17. Это выбор для уже установленной сборки, а не утверждение, что 1.20.1
является самой новой версией Minecraft или поддерживает больше модов, чем
любая другая версия вообще.

## Проверенные факты

- [Официальный манифест Mojang](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json)
  11.10.2026 возвращал `latest.release=26.3`; дата выпуска в записи —
  15.09.2026. Раннее предположение, что 26.3 подходит для нашего модпака,
  было неверным: новизна базовой игры не подтверждает совместимость модов.
- [Официальный каталог Forge для 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)
  отмечает 47.4.10 как Recommended, 47.4.26 как Latest. Действующий клиент
  и сервер используют именно 47.4.10.
- [Oculus 1.8.0](https://modrinth.com/mod/oculus/version/iQ1SwGc3),
  установленный загрузчик шейдеров, опубликован для Minecraft 1.20.1
  и Forge/NeoForge. Исходный `client-pack/client-modpack.json` теперь
  закрепляет 27 файлов версии `2026.10.11.6`, включая Pehkui; на момент
  этой записи экземпляр владельца ещё сообщает версию `.5` и Pehkui в нём
  отсутствует. В основном сервере 22 JAR, перечисленные в `server/mods-lock.json`.
  Ранее пакет `.5` прошёл сверку 26/26 файлов, но это не подтверждает новую
  установку `.6` или игровой тест всего сочетания.
- Изолированный Tellus 0.8.3 потребовал Forge **не ниже 47.4.20**. Его
  проверяли только на отдельной копии. Новые участки имели задержки тика
  13–15 секунд, а клиентский профиль на 47.4.20 не прошёл сквозной тест.

## Условие смены версии

Сохраняем 1.20.1/47.4.10 для текущего игрового мира. Обновление Forge до
47.4.20+ или Minecraft до 26.3 возможно лишь после проверки **всего**
выбранного набора модов, клиентского профиля TLauncher, шейдера, входа на
сервер, восстановления из копии и генерации новых областей. До этого
изолированные исследования не являются обновлением основной игры.
