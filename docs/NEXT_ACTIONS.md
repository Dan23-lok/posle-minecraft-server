# Продолжение работы после v11

## Подтверждённое состояние (11 октября 2026)

- Основной сервер запущен на Minecraft Java 1.20.1 / Forge 47.4.10 с 23 закреплёнными JAR. Рабочий `world-v2` остаётся процедурным Lost Cities/Terralith, не Землёй. Не менять его файлы чанков на ходу.
- Перед переключением создан холодный ZIP в частном архиве владельца; SHA256 `34f2fbeb9cd47d6ae748414b7723391dc37f6b7f9bad63502bafe72efd2f6d0e`. 72 файла и 100 077 903 распакованных байта прошли CRC и проверку обязательных файлов. Вход игроков после восстановления именно этой копии не проверялся.
- Отдельный тестовый сервер владельца не затрагивать. Сохранённая третья копия не заменяет необходимость нового снимка перед будущей миграцией.
- Клиент v11 установлен в выделенный каталог владельца: Forge `1.20.1-forge-47.4.10`, 29 управляемых файлов, Oculus + DMS включены в настройках. TLauncher читает этот каталог и выбранную версию, но фактический запуск игры и вход владельца на основной сервер **ещё не подтверждены**. Дождаться действия владельца в открытом TLauncher и проверить `logs/latest.log` + процесс с правильным `gameDir`.
- Сайт v13 и GitHub release `v0.1.6-preview` опубликованы и проверены без авторизации. На сайте описан ручной шаг Play в TLauncher; автоматический запуск игры пока отсутствует.

## Ближайшие технические блокеры

1. Изолированная генерация Tellus для Нью-Йорка выявила оторванный верх Empire State Building в сохранённых Anvil чанках. Причина: у явных OSM/Overture building parts алгоритм `overlyingPartFloorY` обрезает широкую опорную часть. Исправление испытывается **только в отдельном стенде**, с независимой BFS проверкой опоры; в главный мир не переносить до доказанного результата.
2. Проверить совпадение полного генератора и LOD/Distant Horizons на перекрывающихся building parts. Закрепить точный выпуск Overture: автоматический `latest` может сменить семантику исходных высот после обновления.
3. После исправления проверить регион Земли в настоящем клиенте: рельеф, интерьер, дороги, руины, фрагменты, FPS и тики. Нужны Москва, американские районы и остальные референсные регионы; один сектор не доказывает полный мир.
4. Географические GeoNames и Natural Earth уже импортированы с проверенными хешами. Разделять полный справочник и фактически созданные игровые районы. Сейчас 0/195 государств помечены полностью сгенерированными и проверенными для появления игрока.
5. Остальные открытые пункты, включая мобов, катастрофы, авиацию, голос, социальные системы, карту сайта и поддержку, вести по `docs/REQUIREMENTS.csv` и `docs/ACCEPTANCE.md`. Не считать наличие JAR игровым испытанием.
6. Для публичного входа устранить передачу пароля игровыми командами без штатного шифрования при `online-mode=false`. До защищённого и проверенного способа входа требовать отдельный игровой пароль, не используемый в иных сервисах; детали и критерий проверки — в `docs/KNOWN_ISSUES.md`.
