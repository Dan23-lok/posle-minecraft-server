# Инструкции для ИИ-агентов проекта «ПОСЛЕ»

Этот файл следует открытой идее [AGENTS.md](https://github.com/agentsmd/agents.md): рядом с исходниками хранятся проверяемые правила для всех агентов. Инструкции пользователя имеют приоритет.

## Цель проекта

Поддерживать один совместимый модпак Minecraft Java **Forge 1.20.1 / 47.4.10 / Java 17** для сервера на Windows и клиентов TLauncher. Сохранять низкую задержку сервера и возможность играть с облегчёнными настройками.

## Перед изменением сборки

1. Проверь совместимость каждого мода с **Forge 1.20.1**, сторону установки (сервер, клиент или обе) и обязательные зависимости в официальном каталоге автора.
2. Закрепи конкретную версию, официальный URL и контрольную сумму SHA-256 или SHA-512 в манифесте. Не скачивай исполняемый код с непроверенных зеркал.
3. Не включай JAR модов, шейдеры и Minecraft/Forge в GitHub, сайт или установщик без лицензии на распространение. Установщик должен получать файлы из официальных источников.
4. Сначала проверь изменение в `D:\MinecraftServer\staging-v2` с отдельным миром и портом. Не используй Playit для staging.
5. При изменении генерации мира создавай новый мир; существующий мир и резервные копии сохраняй.

## Безопасность

- Никогда не публикуй Playit secret, код приглашения, пароли, файлы авторизации игроков, `ops.json` с данными реальных игроков, логи с IP-адресами, мир, резервные копии или локальные пути профиля пользователя.
- Не отключай проверку входа. Не включай RCON или Query без отдельной необходимости.
- Для доступа из интернета используй только предусмотренный игровой туннель на порт Minecraft. Адрес сайта и сам туннель не дают абсолютной защиты от DDoS; не обещай её.
- Перед переносом в production проверь резервную копию, останови сервер командой `stop`, проверь новые конфиги и только затем запускай.

## Проверка и спорные решения

- Сверяй утверждения о модах и лицензиях с первичными источниками.
- Для изменений сервера и установщика проси независимого агента проверить совместимость, безопасность и реальные результаты запуска. Не принимай мнение агента без воспроизводимой проверки.
- Проверяй запуск клиента и сервера, загрузку сайта и скачивание полного установщика. Указывай, какие проверки были выполнены, а какие остались невозможны.
- Не называй процедурный мир копией Земли 1:1 и не обещай автоматически построенные реальные города, аэропорты или FPS, которых сборка не гарантирует.

## Структура

- `client-pack/` — исходники установщика и закреплённый манифест.
- `website/` — статическая версия публичного сайта и ссылка на установщик.
- `server/` — безопасные для публикации шаблоны и перечень серверных модов.
