# Сайт «ПОСЛЕ»

Следуй инструкциям в `../AGENTS.md`.

- Публичная страница должна честно описывать фактически установленную сборку.
- Кнопка загрузки должна вести на существующий проверенный ZIP установщика.
- Не помещай секретный код приглашения, Playit ключи или данные игроков в HTML, CSS, JS и метаданные.
- Проверяй мобильную ширину 375 px, обычный экран и доступность кнопки копирования адреса.
