# ПОСЛЕ

Разрабатываемый хоррор-сервер Minecraft Java для друзей. Действующая основа — Forge 1.20.1, Java 17 и процедурный мир с Lost Cities/Terralith. Моды сложности, бедствий, оружия и авиации входят в сборку; выполнение всех игровых сценариев ещё не проверено.

**[Сайт проекта](https://afterfall-apocalypse.mika231477.chatgpt.site/)** · **[опубликованный установщик v9](https://github.com/Dan23-lok/posle-minecraft-server/releases/download/v0.1.5-preview/POSLE-ClientInstaller-v9.zip)**

## Что находится в репозитории

- `AGENTS.md`: проектные правила для ИИ-агентов.
- `docs/REQUIREMENTS.csv`: 82 исходных пункта и 31 отдельная географическая задача/проверка из дополнения, со статусами и доказательствами; `docs/ACCEPTANCE.md` отмечает результаты игровых ворот A–G, `docs/PERFORMANCE.md` хранит измерения, а `docs/KNOWN_ISSUES.md` описывает ограничения.
- `geodata/`: происхождение и справочник географических данных, а также `WORLD_COVERAGE.csv` с честным статусом 195 стран. Исходные большие наборы хранятся локально вне Git.
- `docs/ASSET_SOURCES.csv` и `docs/COMPATIBILITY.csv`: список конкретных файлов, источников, хешей, сторон установки и границ проверки; воспроизводится скриптом `tools/build_asset_ledgers.py` с Python 3.
- `client-pack/`: установщик, который скачивает закреплённые версии модов из официальных источников и проверяет SHA-256 или SHA-512 по манифесту.
- `website/`: статическая страница с инструкцией и кнопкой скачивания установщика.
- `server/`: список компонентов и исходники исправленного мода авторизации; **живой мир, секреты и аккаунты здесь не хранятся**.

## Подключение

1. На сайте скачать ZIP установщика и запустить `Install-Client.cmd` после распаковки.
2. В TLauncher выбрать отдельную папку, подготовленную установщиком, и профиль Forge 1.20.1 / 47.4.10.
3. В сетевой игре указать `cairo-worrisome.tun.ply.gg`.
4. Получить личный код регистрации у владельца сервера. Код в репозитории и на сайте не публикуется.

Браузер не устанавливает Java-приложение без действий пользователя. Установщик автоматизирует скачивание и настройку файлов; выбор папки/профиля в TLauncher может потребоваться вручную. Опциональный локальный обработчик `posle://play` установлен на проверяемом ПК. Его прямой системный вызов проверил файлы и создал маркер успеха, но открытие TLauncher после клика на опубликованном сайте визуально не подтверждено. Кнопка не нажимает Play и не выполняет вход в сервер автоматически. См. `docs/ACCEPTANCE.md` и `docs/KNOWN_ISSUES.md`.

## Реалистичность мира

Действующий `world-v2` **не является картой Земли** и не воссоздаёт Москву или американские мегаполисы. Изолированный Tellus 0.8.3 создал около 0,134 км² Москвы и, на другом стенде, около 0,037 км² Нью-Йорка около Empire State Building. [Нью-йоркский отчёт с настоящими игровыми кадрами](docs/evidence/POSLE-Earth-NewYork-2026-10-11.md) содержит проверенные координаты восьми контуров. Интерьеры повторяются, геометрия высот составных зданий дефектна, руины/аэропорты и огромные города не построены. При генерации новых участков наблюдались задержки серверного тика; экспериментальный патч высот в основной мир не перенесён. См. `docs/GEOGRAPHY_DATA.md`, `docs/TELLUS_GEOREFERENCE.md`, `docs/EARTH_ENGINE_DECISION.md` и `geodata/MOSCOW_STAGE.md`.

## Источники

Версии и хеши указаны в `client-pack/client-modpack.json` и серверном перечне. Формат проектных правил основан на [AGENTS.md](https://github.com/agentsmd/agents.md). Игровые моды и Minecraft принадлежат их авторам; репозиторий не перепубликует их файлы.

На 11.10.2026 файлы клиента и сервера с одинаковыми именами сверены по
установленным байтам (13/13). В CSV поле `manifest_hash_relation` отмечает
один случай разных алгоритмов хеша: сами манифесты не доказывают равенство
этих файлов без сверки установленных экземпляров. Совпадение файлов не
доказывает успешный запуск клиента и игровые механики.
