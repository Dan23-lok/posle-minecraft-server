# ПОСЛЕ — установка клиента

Установщик создаёт отдельную папку игры, скачивает моды с официальных страниц Modrinth и CurseForge, проверяет хеш каждого файла и устанавливает официальный Minecraft Forge 1.20.1 / 47.4.10 вместе с переносимой Java 17. Администраторские права не нужны. Сам Minecraft, TLauncher и учётная запись в архив не входят.

## Первый запуск

1. Распакуйте архив и откройте `Install-Client.cmd`. Дождитесь сообщения `Ready`: при первом запуске будет скачано несколько сотен мегабайт.
2. Установщик откроет TLauncher, если он найден на компьютере. В настройках TLauncher **один раз** задайте папку игры `%APPDATA%\.minecraft-horror-apocalypse`.
3. Выберите **Forge 1.20.1 / 47.4.10** (`1.20.1-forge-47.4.10`) и запустите игру. Если TLauncher показывает собственный список версий, выберите в нём ту же версию Forge **без OptiFine**: сборка использует Oculus и Embeddium. Установщик не управляет внутренним выбором версии TLauncher.
4. В «Сетевой игре» введите адрес **`cairo-worrisome.tun.ply.gg`**. При первом входе придумайте отдельный пароль; код приглашения получите у владельца сервера.

После обновления модпака повторно запустите `Install-Client.cmd`. Файлы с правильным хешем не скачиваются заново. Установщик удаляет устаревшие файлы своей сборки только при совпадении сохранённого хеша; чужие моды и пакеты остаются. Старый Flashier Flashlights удаляется только если его хеш совпадает с файлом нашего предыдущего установщика.

## Графика

Установщик приблизительно определяет видеокарту и память и выбирает начальный профиль **Low**, **Balanced** или **Cinematic**. На Low и Balanced шейдер установлен, но выключен; на Cinematic включается DMS. Это начальная оценка, не измерение FPS. Клиентский мод DynamicRenderDistance меняет дальность прорисовки во время игры по текущему FPS. Нажмите **F8** в игре и задайте максимум **8 чанков**, поскольку сервер отдаёт 8 чанков.

Запуск с явным профилем:

```powershell
Install-Client.cmd -GraphicsProfile Low
Install-Client.cmd -GraphicsProfile Balanced
Install-Client.cmd -GraphicsProfile Cinematic
Install-Client.cmd -NoShader
Install-Client.cmd -NoResourcePack
```

Повторный запуск той же версии без явного профиля сохраняет выбранный профиль и настройки, которые игрок изменил в игре. При обновлении версии сборки установщик возвращает свои графические ключи к настройкам этого профиля; остальные строки `options.txt` сохраняются. Fresh Animations и Tissou's Zombie Pack включаются на всех трёх профилях; Tissou располагается выше Fresh по приоритету. При обновлении установщик включает новые паки сборки и сохраняет другие выбранные вами ресурс-паки. Если они снижают FPS, используйте `-NoResourcePack`.

`-NoShader` не скачивает шейдер, выключает его в Oculus и удаляет старый файл шейдера, если тот был установлен этим установщиком и его хеш не изменился. `-NoResourcePack` так же пропускает ресурс-паки сборки, выключает их и удаляет ранее установленные файлы с совпадающими хешами. Другие шейдеры и ресурс-паки остаются на диске; другие включённые ресурс-паки остаются выбранными. Если DMS не запускается на вашей видеокарте, используйте `-GraphicsProfile Low -NoShader`. Шейдеры всегда потребляют ресурсы; одинаковый FPS на всех компьютерах гарантировать нельзя.

## Что входит

- Мир катастроф, заражённые орды, оружие TaCZ и фонарик Powered Flashlight работают на сервере и клиентах.
- Immersive Aircraft и Civilian Aviation добавляют самолёты и вертолёты; они должны стоять у всех игроков.
- Not Enough Animations, EMF/ETF, Fresh Animations, Tissou's Zombie Pack, Embeddium, Oculus, DynamicRenderDistance, Entity Culling, ImmediatelyFast, звуки и шейдер работают только у игрока.
- Powered Flashlight выбран для совместимости с более старыми видеокартами. Он работает без отдельного мода динамического света, используя обычные блоки света.

Установщик не удаляет посторонние моды и не заменяет файл с неправильным хешем без вашего ведома. Для этого набора нужна отдельная папка игры. Моды с ограничениями на распространение не вложены в архив: установщик скачивает их с официальных адресов.
